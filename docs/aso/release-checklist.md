## 反映後の測定計画

変更前後で条件をそろえ、数字を作らずApp Store Connectの実測値を記録する。

| 記録項目 | 条件 |
|---|---|
| 主指標 | 初回ダウンロード数 |
| 補助指標 | インプレッション、プロダクトページ閲覧数、コンバージョン率、検索流入の初回ダウンロード |
| 国・地域 | 日本 |
| デバイス | iPhoneを主集計。iPadは分ける |
| 期間 | 変更前14日と変更後14日。曜日構成をそろえ、可能なら28日でも確認 |
| 流入元 | App Store検索を中心に、閲覧、ブラウズ、Webリファラ、Appリファラを分ける |
| 外部要因 | 広告出稿、SNS投稿、掲載、価格・課金変更、アプリ更新、障害、季節イベントを日別に記録 |

変更ログには、反映日時（JST）、変更したテキスト/画像の版、ビルド番号、対象ローカライズ、外部施策を残す。検索語別順位や需要は専用データがない限り「未計測」とする。短期の増減だけでASO効果を断定しない。
